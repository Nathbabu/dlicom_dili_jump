# Dili Jump // Dlicom Cyber Arcade

Dili Jump is an arcade game featuring **Dili**, the official mascot of Dlicom.

## Features
- **8 Selectable Dili Suit Colors**: Neon Mint, Cyber Pink, Acid Lime, Sky Cyan, Void Purple, Crimson Fury, Sovereign Gold, Cobalt Shield.
- **Dynamic Character Animation**: Action-driven jump, fall, and rocket booster flight.
- **Global Real-Time Leaderboard**: Live high scores synced via cloud database.
- **Cross-Platform**: Responsive controls for both Mobile and Desktop.

## Local Setup
```bash
npm install
node server.js
# Open http://localhost:8080
```
